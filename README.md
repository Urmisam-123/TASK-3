Task 3: SQL for Data Analysis
Objective
The objective of this task is to use SQL queries to extract, manipulate, and analyze structured data from an e-commerce database.

Tool Used
SQLite
Programiz Online SQL Editor
Dataset
The existing e-commerce dataset provided in the Programiz SQL environment was used for this task.

Tables Used
Customers
Orders
SQL Concepts Used
The following SQL concepts were implemented:

SELECT
WHERE
ORDER BY
GROUP BY
INNER JOIN
LEFT JOIN
Aggregate Functions
SUM()
AVG()
MAX()
MIN()
COUNT()
Subqueries
HAVING
Views
Indexes
Analysis Performed
Retrieved customer and order information using SELECT.
Filtered records using WHERE.
Sorted records using ORDER BY.
Grouped data using GROUP BY.
Combined customer and order data using INNER JOIN and LEFT JOIN.
Calculated total revenue using SUM().
Calculated average order value using AVG().
Identified the highest-value order using a subquery.
Calculated customer-wise spending.
Counted the number of orders per customer.
Used HAVING to filter grouped results.
Created a view for customer order details.
Created indexes to improve query performance.

Outcome
This task helped in understanding how SQL can be used to retrieve, filter, join, aggregate, and analyze structured e-commerce data efficiently.

Conclusion
The task provided practical experience with SQL data analysis techniques, including joins, aggregate functions, subqueries, views, and indexes.
